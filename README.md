# Odd or Even Determiner

A Python program which determines if your integer (input) is odd or even.

## How to Run
1. Open odd_or_even.py 
2. Run the program
3. Enter an integer
4. Receive your result

## How does it work? 
1. The program firstly receives your input.
2. Then, the program calculates the modulo between the input and 2 to find the remainder.
3. The program now determines if the remainder is either 1 or 0.
4. The program prints odd if the remainder is 1.
5. The program prints even if the remainder is 0.
